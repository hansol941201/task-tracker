토큰은 어떻게 만드나요?

1. 데이터를 담을 저장소 만들기

  • 새 저장소를 하나 만듭니다 — 예: task-tracker-data
  • Private 로 두는 것을 권합니다. 업무 내용이 공개되지 않습니다.

2. Fine-grained 토큰 발급

  1. 깃허브 → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token 을 누릅니다.
  3. Repository access → Only select repositories → 방금 만든 저장소 하나만 선택
  4. Permissions → Repository permissions → Contents 를 Read and write 로 변경
  5. 생성된 토큰을 복사해 위 칸에 붙여넣고 [연결하기] 를 누릅니다.

3. 팀원과 함께 쓰기

  • 저장소 Settings → Collaborators 에서 팀원을 초대합니다.
  • 팀원도 각자 자기 토큰을 만들어 같은 소유자·저장소·파일 경로 를 입력하면 됩니다.
  • 저장할 때마다 자동으로 커밋되고, 새로고침하면 최신본을 받아옵니다.

주의

  • 토큰은 이 브라우저의 localStorage 에만 저장됩니다. 공용 PC 에서는 쓰고 나서 [연결 해제] 를 눌러 주세요.
  • 토큰을 저장소 안 파일에 적어 커밋하면 깃허브가 자동으로 폐기합니다. 절대 커밋하지 마세요.
  • 두 사람이 동시에 고치면 나중에 저장한 쪽이 물어본 뒤 덮어씁니다.
