# B2B 업무 트래커

팀의 루틴 업무와 프로젝트를 한 화면에서 관리하는 단일 HTML 앱입니다.
설치도, 서버도 필요 없습니다. 브라우저에서 열면 바로 씁니다.

## 바로 사용하기

**[업무 트래커 열기](https://hansol941201.github.io/task-tracker/)**

## 화면 구성

| 탭 | 용도 |
| --- | --- |
| 📅 오늘 | 팀 멤버별 오늘 할 일 — 루틴 체크와 진행중 프로젝트를 카드로 |
| 👥 팀별 보기 | 팀 단위로 묶어서 보기 |
| 🚀 자동화 | 팀에서 만든 자동화·대시보드 앱 모음 |
| 📖 매뉴얼 | 담당자별 업무 매뉴얼 |
| ⚙️ 관리 | 팀·멤버·루틴·업무 등록과 데이터 백업 |

## 업무의 두 종류

- **🔄 루틴 업무** — 매일·매주·매월·분기·매년 반복. 주기 안에서 한 번
  체크하면 그 주기는 완료로 처리되고, 다음 주기가 시작되면 자동으로
  미완료로 돌아갑니다.
- **🚀 프로젝트 / 🔁 루틴성 업무** — 일회성 작업. 프로젝트는 보조 업무로
  쪼갤 수 있고, 보조 업무 진척률의 평균이 메인 진척률에 자동 반영됩니다.

상태는 카드를 눌러 `할 일 → 진행 중 → 보류 → 완료` 순으로 순환합니다.
완료하면 진척률이 100%가 되고 완료일이 기록되며, 한 번 더 누르면 취소됩니다.

## 데이터 저장

브라우저 `localStorage` 의 `task_tracker_v19` 키에 JSON으로 저장합니다.

- 추가·수정·삭제하는 즉시 저장됩니다
- 새로고침하거나 브라우저를 껐다 켜도 그대로 유지됩니다
- 깃허브 동기화를 켜지 않으면 아무 데도 보내지 않습니다

### 백업과 이동

상단 **내보내기** 로 JSON 파일을 받고, **가져오기** 로 되돌립니다.
PC를 옮기거나 브라우저를 바꿀 때 이 파일 하나면 됩니다.

### 여럿이 함께 쓰기 — Firebase 실시간 공동 저장

팀 전원이 같은 데이터를 봅니다. 따로 설정할 것도, 로그인할 것도 없습니다.

- 업무를 추가·수정·삭제하거나 루틴을 체크하면 곧바로 팀 데이터에 올라갑니다
- 다른 팀원의 변경은 실시간으로 화면에 들어옵니다
- 새로고침하면 항상 팀의 최신 데이터가 표시됩니다
- 인터넷이 끊기면 이 PC에 저장해 두었다가, 연결이 돌아오면 다시 올립니다

상단 배지가 현재 상태를 보여줍니다 — **연결 중** · **팀 데이터 동기화** · **연결 오류**.
배지를 누르면 연결 방식과 마지막 동기화 시각을 볼 수 있습니다.

| 항목 | 값 |
| --- | --- |
| Realtime Database | `b2b-task-tracker-39144-default-rtdb.asia-southeast1` |
| 공용 데이터 경로 | `shared/taskTracker` |
| 연결 방식 | Firebase Web SDK 실시간 리스너 (막히면 2초 주기 동기화로 자동 전환) |

두 사람이 거의 동시에 저장해도, 서로 다른 항목을 고쳤다면 양쪽 변경이 모두 남습니다.
마지막으로 주고받은 스냅샷을 기준점으로 삼아 "내가 바꾼 것"과 "남이 바꾼 것"을
가려낸 뒤 합치고, 쓰기는 트랜잭션(SDK) 또는 ETag 조건부 쓰기(REST)로 처리합니다.

> **공개 데이터베이스입니다.** 로그인 없이 누구나 읽고 쓸 수 있는 방식이라
> 주소를 아는 사람은 데이터를 볼 수 있습니다. 민감한 내용은 넣지 마세요.
> 백업이 필요하면 상단 **내보내기** 로 JSON 파일을 받아 두세요.
