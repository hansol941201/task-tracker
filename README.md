# B2B 업무 트래커

팀의 루틴 업무와 프로젝트를 한 화면에서 관리하는 단일 HTML 앱입니다.
설치도, 서버도 필요 없습니다. 브라우저에서 열면 바로 씁니다.

## 바로 사용하기

**[업무 트래커 열기](https://hansol941201.github.io/task-tracker/)**

## 화면 구성

| 탭 | 용도 |
| --- | --- |
| 📅 오늘 | 팀 멤버별 오늘 할 일 — 루틴 체크와 진행중 프로젝트를 카드로 |
| 👥 팀별 보기 | 팀 단위로 묶어서 보기 |
| 🚀 자동화 | 팀에서 만든 자동화·대시보드 앱 모음 |
| 📖 매뉴얼 | 담당자별 업무 매뉴얼 |
| ⚙️ 관리 | 팀·멤버·루틴·업무 등록과 데이터 백업 |

## 업무의 두 종류

- **🔄 루틴 업무** — 매일·매주·매월·분기·매년 반복. 주기 안에서 한 번
  체크하면 그 주기는 완료로 처리되고, 다음 주기가 시작되면 자동으로
  미완료로 돌아갑니다.
- **🚀 프로젝트 / 🔁 루틴성 업무** — 일회성 작업. 프로젝트는 보조 업무로
  쪼갤 수 있고, 보조 업무 진척률의 평균이 메인 진척률에 자동 반영됩니다.

상태는 카드를 눌러 `할 일 → 진행 중 → 보류 → 완료` 순으로 순환합니다.
완료하면 진척률이 100%가 되고 완료일이 기록되며, 한 번 더 누르면 취소됩니다.

## 데이터 저장

브라우저 `localStorage` 의 `task_tracker_v19` 키에 JSON으로 저장합니다.

- 추가·수정·삭제하는 즉시 저장됩니다
- 새로고침하거나 브라우저를 껐다 켜도 그대로 유지됩니다
- 깃허브 동기화를 켜지 않으면 아무 데도 보내지 않습니다

### 백업과 이동

상단 **내보내기** 로 JSON 파일을 받고, **가져오기** 로 되돌립니다.
PC를 옮기거나 브라우저를 바꿀 때 이 파일 하나면 됩니다.

### 여럿이 함께 쓰기 — 깃허브 동기화 (선택)

상단 **☁ 로컬만** 배지를 누르면 깃허브 동기화 설정이 열립니다.
업무 데이터를 깃허브 저장소에 JSON 파일 하나로 보관해서, 여러 PC와
팀원이 같은 데이터를 보게 만듭니다.

준비물:

1. 데이터를 담을 저장소 하나 (예: `task-tracker-data`, **Private 권장**)
2. 그 저장소에만 권한을 준 **Fine-grained personal access token**
   — Repository access 는 `Only select repositories`,
     Permissions → Repository permissions → **Contents: Read and write**

설정 화면에 소유자 · 저장소 · 파일 경로 · 브랜치 · 토큰을 넣고
[연결하기] 를 누르면 됩니다.

- 저장할 때마다 3초 모아서 자동으로 커밋합니다
- 새로고침하면 깃허브의 최신본을 먼저 받아옵니다
- [깃허브에서 받기] / [깃허브에 올리기] 로 직접 맞출 수도 있습니다
- 두 사람이 동시에 고치면, 나중에 저장하는 쪽에 덮어쓸지 물어봅니다
- 팀원과 같이 쓰려면 저장소에 Collaborator 로 초대하고, 각자 자기 토큰을
  만들어 같은 소유자 · 저장소 · 경로를 입력하면 됩니다

> **토큰 주의** — 토큰은 그 브라우저의 `localStorage` 에만 저장되고
> 깃허브 API 외에는 어디로도 나가지 않습니다. 그래도 공용 PC 에서는
> 쓰고 나서 [연결 해제] 를 눌러 지워 주세요. 토큰을 저장소 안 파일에
> 적어 커밋하면 깃허브가 자동으로 폐기합니다. 절대 커밋하지 마세요.

## 단축키

- `Ctrl + N` — 새 업무 추가
- `Esc` — 열려 있는 모달 닫기

## 구조

```text
index.html    앱 전체 (HTML · CSS · JS 단일 파일)
.nojekyll     GitHub Pages 가 파일을 그대로 서빙하도록
```

빌드 단계가 없습니다. `index.html` 을 고치고 커밋하면 그게 배포입니다.
